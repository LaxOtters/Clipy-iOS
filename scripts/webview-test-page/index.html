Load failures

When a load fails while this page is open, the app keeps this page and shows a Snackbar instead of the error screen.

Connection refused

"Couldn't load this page" Snackbar. This page stays.

Unknown host

"Couldn't load this page" Snackbar. This page stays.

Plain http external host (blocked by ATS)

"Couldn't load this page" Snackbar. This page stays.

Stop the server, then tap ↻ in the bottom sheet

"Couldn't load this page" Snackbar. This page stays.

Server 500 response

The server's 500 page shows, not the app error screen.

Missing path (404)

The server's 404 page shows, not the app error screen.

To see a failure on the first load, pass one of the failing URLs above as the launch argument. The app error screen then appears: connection refused and unknown host use the server connection message, the ATS block uses the secure connection message.
